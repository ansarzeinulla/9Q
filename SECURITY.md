# Security Policy

## Supported Versions

We actively maintain and patch security vulnerabilities on the following versions:

| Version | Supported          |
| ------- | ------------------ |
| v1.1.x  | :white_check_mark: |
| < v1.1  | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities via public GitHub issues. Instead, report any memory safety issues, buffer overflows, or WebAssembly sandbox escapes by emailing the maintainer directly at **ansar.zeinulla@nu.edu.kz**.
