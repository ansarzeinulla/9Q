# Эң кыска оюн генерациясы

*Башка тилдерде окуу: [English](README.md) | [Қазақша](README_kk.md) | [Русский](README_ru.md) | [Кыргызча](README_ky.md)*

Бул папка макаладагы толук эрте оюн натыйжасы үчүн колдонулган эң кыска терминалдык оюн издөөсүн камтыйт.

Макалада `11` жарым жүрүшкө чейин терминалдык абал жок экени айтылат жана Ак/P1 үчүн акыркы Казан эсеби `88-10` болгон `11` жарым жүрүштөгү бир терминалдык линия берилет.

## Файлдар

| Файл | Максаты |
| :--- | :--- |
| `find_shortest_game.cpp` | Өз алдынча эрежелер симулятору жана эң кыска оюн издегичи. |
| `Makefile` | `find_shortest_game` бинарын жыйнайт. |
| `shortest_terminal_game.txt` | Сакталган 11 жарым жүрүштүк терминалдык линия. |
| `shortest_candidate_replay.tsv` | Сакталган candidate линиясы үчүн replay таблицасы. |
| `shortest_depth_proof.tsv` | Далил катмарлары боюнча сакталган breadth-search статистикасы. |

Бул компонент өз алдынча жана `engine/` папкасына көз каранды эмес.

## Жыйноо

```bash
cd FINAL/shortest-game-generation
make
```

## Сакталган candidate-ти текшерүү

```bash
./find_shortest_game --verify-only
```

Бул сакталган 11 жарым жүрүштүк линияны кайра ойнойт жана анын терминалдык экенин текшерет. Ал `shortest_terminal_game.txt` жана `shortest_candidate_replay.tsv` файлдарын кайра жазат.

## Толук издөө жана далилди иштетүү

```bash
./find_shortest_game
```

Бул үч нерсе кылат:

1. Конфигурацияланган тереңдик ичинде терминалдык линия издейт.
2. `11` жарым жүрүшкө чейин терминалдык edge жок экенин далилдейт.
3. `shortest_terminal_game.txt`, `shortest_candidate_replay.tsv` жана `shortest_depth_proof.tsv` файлдарын кайра түзөт.

Далил кадамы абдан чоң frontier-лерди материалдайт жана олуттуу убакыт менен эс тутум талап кылышы мүмкүн.

## Сакталган эң кыска линия

`shortest_terminal_game.txt` төмөнкүнү камтыйт:

```text
1. 98 22
2. 87 12
3. 76 25
4. 65 13
5. 93 25
6. 54
```

Жүрүш нотациясы - `selected_pit``landing_pit`, экөө тең бирден башталат. Мисалы, `98` оюнчу `9`-чуңкурду тандаганын жана акыркы себилген кумалак `8`-чуңкурга түшкөнүн билдирет. Эгер жүрүш Туздук түзсө, нотацияга `x` кошулат.

Акыркы жүрүш - оюндун Ак/P1 жасаган 11-жарым жүрүшү жана ал Казандарды `88-10` эсеби менен аяктайт.

## Кошумча аргументтер

```bash
./find_shortest_game --verify-only
./find_shortest_game --no-proof
./find_shortest_game --max-depth 11 --beam 1000
```

`--verify-only` - эң тез кайра чыгаруу текшерүүсү. Демейки команда толук далилге багытталган иштетүү болуп саналат.
