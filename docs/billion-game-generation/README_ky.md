# Миллиард оюн генерациясы

*Башка тилдерде окуу: [English](README.md) | [Қазақша](README_kk.md) | [Русский](README_ru.md) | [Кыргызча](README_ky.md)*

Бул папка макаладагы эмпирикалык оюн дарагын талдоо үчүн колдонулган кокустук playout симуляторун камтыйт.

Макалада төмөнкүлөр билдирилет:

- `1,000,000,000` симуляцияланган кокустук оюн
- `124,474,599,634` байкалган такта позициясы
- Бул позициялар боюнча `871,191,286,723` топтолгон мыйзамдуу жүрүш
- Кокустук оюндун орточо узундугу болжол менен `124.474` жарым жүрүш
- Эмпирикалык орточо бутактануу коэффициенти болжол менен `7.00`

Кошулган `billion_game_statistics.txt` - сакталган миллиард оюндук эсептегич файлы.

## Файлдар

| Файл | Максаты |
| :--- | :--- |
| `generate_billion_games.cpp` | Random-vs-random симулятору жана статистика жыйнагычы. |
| `Makefile` | `generate_billion_games` бинарын жыйнайт. |
| `billion_game_statistics.txt` | Макала үчүн иштетүүдөн алынган миллиард оюндук статистика. |
| `../engine/togyzkumalak_rules.*` | Симулятор колдонгон жергиликтүү эрежелер көз карандылыгы. |
| `../engine/position_hash.*` | Симулятор колдонгон жергиликтүү хештөө көз карандылыгы. |

## Жыйноо

```bash
cd FINAL/billion-game-generation
make
```

Makefile төмөнкүлөрдү компиляциялайт:

```text
generate_billion_games.cpp ../engine/togyzkumalak_rules.cpp ../engine/position_hash.cpp
```

## Чакан тест иштетүү

```bash
./generate_billion_games --num=1000 --seed=1 --threads=1 --fresh --stat=sample_billion_game_statistics.txt
```

## Симулятор режимдеринин бенчмарки

```bash
./generate_billion_games --bench=100000 --seed=1 --threads=10
```

Жеткиликтүү режимдер:

| Режим | Мааниси |
| :--- | :--- |
| `env` | Стандарттуу RNG менен баштапкы `ToguzEnv` жолу. |
| `env-fast-rng` | SplitMix RNG менен баштапкы `ToguzEnv` жолу. |
| `fast` | Ыкчам бир агымдуу симулятор. |
| `fast-prebuffer` | Алдын ала эсептелген кокустук маанилери бар ыкчам симулятор. |
| `fast-parallel` | Worker агымдарына бөлүнгөн ыкчам симулятор. Бул демейки режим. |

## Миллиард оюндук иштетүүнү кайра чыгаруу

Кошулган `billion_game_statistics.txt` файлына кошулуп кетпеши үчүн жаңы чыгаруу файлын колдонуңуз:

```bash
./generate_billion_games --num=1000000000 --seed=709791810521833 --threads=10 --fresh --stat=billion_game_reproduction_statistics.txt
```

Маанилүү: симулятор stats жолундагы бар эсептегичтерди жүктөйт, жаңы иштетүүнү кошот жана файлды кайра жазат. Эгер команданы кошулган `billion_game_statistics.txt` файлына каршы иштетсеңиз, миллиард оюндук эсептер бар миллиард оюндук эсептердин үстүнө кошулат.

Бар чыгаруу файлын эске албай, нөлдөн баштоо керек болгондо `--fresh` колдонуңуз.

Иштөө убактысы CPU өзөктөрүнүн санына жана компилятор оптимизациясына катуу көз каранды. Толук миллиард оюндук иштетүү - узак эксперимент; build тууралыгын текшерүү үчүн адегенде кичине `--num` маанилерин колдонуңуз.

## Пайдалуу опциялар

```bash
./generate_billion_games --num=1000000 --seed=12345
./generate_billion_games --num=1000000 --threads=10
./generate_billion_games --num=1000000 --max-steps=10000
./generate_billion_games --num=1000000 --fresh --stat=custom_billion_game_statistics.txt
./generate_billion_games --num=1000000 --mode=fast-parallel
```

## Чыгаруу эскертүүлөрү

- `billion_game_statistics.txt` ичиндеги эсептегичтер пайыз эмес, raw counts.
- Файл адам окуй ала турган summary менен башталат, андан кийин скрипттер жана так текшерүүлөр үчүн raw `%key value` эсептегичтерин сактайт.
- Ак түс - `PLAYER_1`, баштапкы жайгашуудан биринчи оюнчу.
- Жүрүш индекстүү эсептегичтер plies/жарым жүрүштөрдү колдонот: `1` жүрүшү - Актын биринчи жүрүшү, `2` жүрүшү - Каранын биринчи жүрүшү жана ушинтип уланат.
- `legalMoveAtPos` нөлдөн башталган чуңкур позицияларын `0..8` колдонот.
- `kumalakAtPos` `0..7` колдонот, анткени ишке ашырылган эреже боюнча тогузунчу чуңкурда Туздук түзүү мыйзамдуу эмес.
- `featureTrackedGames` - advanced feature эсептегичтеринин бөлүмү.
