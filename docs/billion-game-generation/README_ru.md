# Генерация миллиарда партий

*Читать на других языках: [English](README.md) | [Қазақша](README_kk.md) | [Русский](README_ru.md) | [Кыргызча](README_ky.md)*

Эта папка содержит симулятор случайных playout-ов, использованный для эмпирического анализа дерева игры в статье.

В статье сообщается:

- `1,000,000,000` симулированных случайных партий
- `124,474,599,634` наблюдаемых позиций доски
- `871,191,286,723` накопленных легальных ходов по этим позициям
- Средняя длина случайной партии около `124.474` полуходов
- Эмпирический средний коэффициент ветвления около `7.00`

Включенный `billion_game_statistics.txt` - сохраненный файл счетчиков миллиарда партий.

## Файлы

| Файл | Назначение |
| :--- | :--- |
| `generate_billion_games.cpp` | Симулятор random-vs-random и сборщик статистики. |
| `Makefile` | Собирает `generate_billion_games`. |
| `billion_game_statistics.txt` | Включенная статистика миллиарда партий из запуска для статьи. |
| `../engine/togyzkumalak_rules.*` | Локальная зависимость правил, используемая симулятором. |
| `../engine/position_hash.*` | Локальная зависимость хеширования, используемая симулятором. |

## Сборка

```bash
cd FINAL/billion-game-generation
make
```

Makefile компилирует:

```text
generate_billion_games.cpp ../engine/togyzkumalak_rules.cpp ../engine/position_hash.cpp
```

## Запуск небольшого теста

```bash
./generate_billion_games --num=1000 --seed=1 --threads=1 --fresh --stat=sample_billion_game_statistics.txt
```

## Бенчмарк режимов симулятора

```bash
./generate_billion_games --bench=100000 --seed=1 --threads=10
```

Доступные режимы:

| Режим | Значение |
| :--- | :--- |
| `env` | Исходный путь `ToguzEnv` со стандартным RNG. |
| `env-fast-rng` | Исходный путь `ToguzEnv` с SplitMix RNG. |
| `fast` | Компактный однопоточный симулятор. |
| `fast-prebuffer` | Компактный симулятор с заранее вычисленными случайными значениями. |
| `fast-parallel` | Компактный симулятор, разделенный между worker-потоками. Это режим по умолчанию. |

## Воспроизведение запуска на миллиард партий

Используйте новый выходной файл, чтобы не добавлять данные к включенному `billion_game_statistics.txt`:

```bash
./generate_billion_games --num=1000000000 --seed=709791810521833 --threads=10 --fresh --stat=billion_game_reproduction_statistics.txt
```

Важно: симулятор загружает существующие счетчики из пути stats, добавляет новый запуск и перезаписывает файл. Если запустить команду с включенным `billion_game_statistics.txt`, счетчики миллиарда партий будут добавлены поверх уже существующих счетчиков миллиарда партий.

Используйте `--fresh`, когда нужно игнорировать существующий выходной файл и начать с нуля.

Время выполнения сильно зависит от количества CPU-ядер и оптимизации компилятора. Полный запуск на миллиард партий - долгий эксперимент; сначала используйте небольшие значения `--num`, чтобы проверить сборку.

## Полезные опции

```bash
./generate_billion_games --num=1000000 --seed=12345
./generate_billion_games --num=1000000 --threads=10
./generate_billion_games --num=1000000 --max-steps=10000
./generate_billion_games --num=1000000 --fresh --stat=custom_billion_game_statistics.txt
./generate_billion_games --num=1000000 --mode=fast-parallel
```

## Примечания к выводу

- Счетчики в `billion_game_statistics.txt` являются raw counts, а не процентами.
- Файл начинается с человекочитаемого summary, затем хранит raw счетчики `%key value` для скриптов и точных проверок.
- Белые - это `PLAYER_1`, первый игрок из начальной расстановки.
- Счетчики с индексами ходов используют plies/полуходы: ход `1` - первый ход Белых, ход `2` - первый ход Черных и так далее.
- `legalMoveAtPos` использует позиции лунок с нулевой индексацией `0..8`.
- `kumalakAtPos` использует `0..7`, потому что создание Туздыка на девятой лунке не является легальным по реализованному правилу.
- `featureTrackedGames` - знаменатель для счетчиков advanced feature.
