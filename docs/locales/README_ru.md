# Togyzkumalak-Wasm: высокопроизводительный симулятор комбинаторного пространства состояний

*Читать на других языках: [English](https://github.com/ansarzeinulla/9Q/blob/main/README.md) | [Қазақша](https://github.com/ansarzeinulla/9Q/blob/main/docs/locales/README_kk.md) | [Русский](https://github.com/ansarzeinulla/9Q/blob/main/docs/locales/README_ru.md) | [Кыргызча](https://github.com/ansarzeinulla/9Q/blob/main/docs/locales/README_ky.md)*

*Основная версия документации — [английская](https://github.com/ansarzeinulla/9Q/blob/main/README.md). При расхождении верна английская.*

🎮 **[ИГРАТЬ В БРАУЗЕРЕ](https://9qumalaq.vercel.app/)** | 📖 **[ДОКУМЕНТАЦИЯ API](https://ansarzeinulla.github.io/9Q/)**

**Движок и симулятор Тогызкумалак на C++17: верхняя оценка $1.51 \times 10^{25}$ для пространства состояний, исчерпывающий перебор, показывающий, что ни одна партия не заканчивается раньше 11-го полухода, исследование одного миллиарда случайных партий и движок альфа-бета с компактными 16-байтными записями таблицы транспозиций.**

## 🔬 Архитектура

- **Таблица транспозиций:** таблица фиксированного размера из упакованных 16-байтных записей (`static_assert(sizeof(TTEntry) == 16)`), 64-битный ключ Зобриста, замена с приоритетом по глубине. Поиск однопоточный.
- **Поиск:** минимакс с альфа-бета отсечением, итеративным углублением, упорядочиванием ходов по таблице транспозиций и поиском успокоения (DAGv1, движок из статьи), а также DAGv2 с killer-ходами, эвристикой истории, аспирационными окнами и PVS.
- **Исчерпывающий перебор начала партии:** все 1 559 006 339 легальных ходов из 185 464 053 различных позиций на 10-м полуходе ведут в нетерминальные позиции, и существует терминальная партия длиной 11 полуходов; значит, самая короткая возможная партия длится 11 полуходов. Таблица 2 статьи независимо воспроизведена до 8-го полухода (см. ниже).
- **Симулятор миллиарда партий:** многопоточные случайные партии; агрегированные счётчики полного прогона из $10^9$ партий лежат в `research/sample_billion_game_statistics.txt`.

## 🚀 Демо на WebAssembly
Движок на C++ скомпилирован в WebAssembly через Emscripten и работает полностью в браузере, примерно на 70% скорости нативной сборки в нашем тесте.

**[Сыграть с движком в браузере](https://9qumalaq.vercel.app/)**

## ⚡ Производительность
*Начальная позиция, один поток, новая таблица транспозиций 256 МБ, итеративное углубление. Apple M2 Pro. Число узлов детерминировано; время — медиана 3 запусков и зависит от машины и нагрева. Воспроизвести: `./build/tg_bench_search`.*

| Движок | Сборка | Глубина, завершённая за 1,0 с | Узлов/с (до глубины 9) | Узлов до завершения глубины 9 |
| :--- | :--- | :---: | ---: | ---: |
| DAGv1 (движок из статьи) | Нативная, Apple clang 16 `-O3` | 8 | 3.51M | 7,936,122 |
| DAGv1 (движок из статьи) | Wasm, Emscripten 6.0 / Node 26 (V8) | 7 | 2.42M | 7,936,113 |
| DAGv2 | Нативная, Apple clang 16 `-O3` | 9 (0.26 s) | 3.54M | 934,389 |
| DAGv2 | Wasm, Emscripten 6.0 / Node 26 (V8) | 9 (0.34 s) | 2.77M | 934,389 |

Упорядочивание ходов по таблице транспозиций сокращает число узлов, нужных DAGv1 для завершения глубины 9, с 19 267 114 до 7 936 122 (в 2,43 раза).

## 🛠️ Сборка (CMake)

**Требования:** `cmake >= 3.20`, компилятор C++17 (рекомендуется `clang++`), `make` или `ninja`.

```bash
# 1. Клонировать репозиторий и перейти в него
git clone https://github.com/ansarzeinulla/9Q.git && cd 9Q

# 2. Сгенерировать файлы сборки
cmake -B build -DCMAKE_BUILD_TYPE=Release

# 3. Собрать движок и инструменты
cmake --build build -j

# 4. Запустить тесты и проверку Perft (глубины 1-4: 9, 73, 613, 5199)
ctest --test-dir build
./build/perft_test
```

Сборка движка WebAssembly для веб-демо:

```bash
npm run setup:emscripten   # один раз: устанавливает emsdk в .emsdk/
npm run build:wasm         # пишет web/public/wasm/togyz_engine.{js,wasm}
npm run dev                # запускает демо на http://127.0.0.1:3000
```
