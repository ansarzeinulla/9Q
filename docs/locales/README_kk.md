# Togyzkumalak-Wasm: комбинаторлық күйлер кеңістігінің жоғары өнімді симуляторы

*Құжаттаманың негізгі нұсқасы — [ағылшынша](https://github.com/ansarzeinulla/9Q/blob/main/README.md). Айырмашылық болса, ағылшын нұсқасы дұрыс деп саналады.*

🎮 **[БРАУЗЕРДЕ ОЙНАУ](https://9qumalaq.vercel.app/)** | 📖 **[API ҚҰЖАТТАМАСЫ](https://ansarzeinulla.github.io/9Q/)**

**Тоғызқұмалаққа арналған C++17 қозғалтқышы мен симуляторы: күйлер кеңістігінің $1.51 \times 10^{25}$ жоғарғы бағасы, ешбір ойын 11-жартылай жүрістен бұрын аяқталмайтынын көрсететін толық іздеу, бір миллиард кездейсоқ ойынды зерттеу және ықшам 16 байттық транспозиция кестесі жазбалары бар альфа-бета қозғалтқышы.**

## 🔬 Архитектура

- **Транспозиция кестесі:** оралған 16 байттық жазбалардан тұратын тұрақты өлшемді кесте (`static_assert(sizeof(TTEntry) == 16)`), 64 биттік Зобрист кілті, тереңдігі бойынша басымдықпен ауыстыру. Іздеу бір ағынды.
- **Іздеу:** итеративті тереңдету, транспозиция кестесі бойынша жүрістерді реттеу және тыныштандыру іздеуі бар альфа-бета минимакс (DAGv1, мақаладағы қозғалтқыш), сондай-ақ killer-жүрістер, тарих эвристикасы, аспирациялық терезелер және PVS бар DAGv2.
- **Ойын басын толық іздеу:** 10-жартылай жүрістегі 185 464 053 түрлі позициядан шығатын барлық 1 559 006 339 заңды жүріс ойынды аяқтамайды, ал 11 жартылай жүрістен тұратын аяқталған ойын бар; демек, ең қысқа ойын 11 жартылай жүрістен тұрады. Мақаланың 2-кестесі 8-жартылай жүріске дейін тәуелсіз түрде қайта алынды (төменде қараңыз).
- **Миллиард ойын симуляторы:** көп ағынды кездейсоқ ойындар; $10^9$ ойынның толық жүгірісінің жиынтық есептегіштері `research/sample_billion_game_statistics.txt` файлында.

## 🚀 WebAssembly демосы

## 🛠️ Құрастыру (CMake)

**Талаптар:** `cmake >= 3.20`, C++17 компиляторы (`clang++` ұсынылады), `make` немесе `ninja`.

```bash
# 1. Репозиторийді клондап, оның ішіне өту
git clone https://github.com/ansarzeinulla/9Q.git && cd 9Q

# 2. Құрастыру файлдарын жасау
cmake -B build -DCMAKE_BUILD_TYPE=Release

# 3. Қозғалтқыш пен құралдарды компиляциялау
cmake --build build -j

# 4. Тесттерді және Perft тексерісін іске қосу (1-4 тереңдіктер: 9, 73, 613, 5199)
ctest --test-dir build
./build/perft_test
```

Веб-демоға арналған WebAssembly қозғалтқышын құрастыру:

```bash
npm run setup:emscripten   # бір рет: emsdk-ті .emsdk/ ішіне орнатады
npm run build:wasm         # web/public/wasm/togyz_engine.{js,wasm} жазады
npm run dev                # демоны http://127.0.0.1:3000 мекенжайында іске қосады
```
