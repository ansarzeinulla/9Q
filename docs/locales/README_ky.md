**Тогуз коргоолго арналган C++17 кыймылдаткычы жана симулятору: абалдар мейкиндигинин $1.51 \times 10^{25}$ жогорку баасы, эч бир оюн 11-жарым жүрүштөн мурун бүтпөй турганын көрсөткөн толук издөө, бир миллиард кокустук оюнду изилдөө жана компакттуу 16 байттык транспозиция таблицасынын жазуулары бар альфа-бета кыймылдаткычы.**

## 🔬 Архитектура

- **Транспозиция таблицасы:** таңгакталган 16 байттык жазуулардан турган туруктуу өлчөмдөгү таблица (`static_assert(sizeof(TTEntry) == 16)`), 64 биттик Зобрист ачкычы, тереңдиги боюнча артыкчылык менен алмаштыруу. Издөө бир агымдуу.
- **Издөө:** итеративдик тереңдетүү, транспозиция таблицасы боюнча жүрүштөрдү иреттөө жана тынчтандыруу издөөсү бар альфа-бета минимакс (DAGv1, макаладагы кыймылдаткыч), ошондой эле killer-жүрүштөр, тарых эвристикасы, аспирациялык терезелер жана PVS бар DAGv2.
- **Оюндун башын толук издөө:** 10-жарым жүрүштөгү 185 464 053 ар түрдүү позициядан чыккан бардык 1 559 006 339 мыйзамдуу жүрүш оюнду бүтүрбөйт, ал эми 11 жарым жүрүштөн турган бүткөн оюн бар; демек, эң кыска оюн 11 жарым жүрүштөн турат. Макаланын 2-таблицасы 8-жарым жүрүшкө чейин көз карандысыз түрдө кайра алынды (төмөндө караңыз).
- **Миллиард оюн симулятору:** көп агымдуу кокустук оюндар; $10^9$ оюндун толук жүргүзүүсүнүн жыйынтык эсептегичтери `research/sample_billion_game_statistics.txt` файлында.

## 🛠️ Курастыруу (CMake)

**Талаптар:** `cmake >= 3.20`, C++17 компилятору (`clang++` сунушталат), `make` же `ninja`.

```bash
# 1. Репозиторийди клондоп, анын ичине өтүү
git clone https://github.com/ansarzeinulla/9Q.git && cd 9Q

# 2. Курастыруу файлдарын түзүү
cmake -B build -DCMAKE_BUILD_TYPE=Release

# 3. Кыймылдаткычты жана куралдарды компиляциялоо
cmake --build build -j

# 4. Тесттерди жана Perft текшерүүсүн иштетүү (1-4 тереңдиктер: 9, 73, 613, 5199)
ctest --test-dir build
./build/perft_test
```

Веб-демо үчүн WebAssembly кыймылдаткычын курастыруу:

```bash
npm run setup:emscripten   # бир жолу: emsdk'ни .emsdk/ ичине орнотот
npm run build:wasm         # web/public/wasm/togyz_engine.{js,wasm} жазат
npm run dev                # демону http://127.0.0.1:3000 дарегинде иштетет
```
