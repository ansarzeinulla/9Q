# Ең қысқа ойын генерациясы

*Басқа тілдерде оқыңыз: [English](README.md) | [Қазақша](README_kk.md) | [Русский](README_ru.md) | [Кыргызча](README_ky.md)*

Бұл қалта мақаладағы толық ерте ойын нәтижесі үшін қолданылған ең қысқа терминалдық ойын іздеуін қамтиды.

Мақалада `11` жартыжүріске дейін терминалдық күй жоқ екені хабарланады және Ақ/P1 үшін соңғы Қазан есебі `88-10` болатын `11` жартыжүрістегі бір терминалдық сызық беріледі.

## Файлдар

| Файл | Мақсаты |
| :--- | :--- |
| `find_shortest_game.cpp` | Дербес ережелер симуляторы және ең қысқа ойын іздегіші. |
| `Makefile` | `find_shortest_game` бинарын құрастырады. |
| `shortest_terminal_game.txt` | Сақталған 11 жартыжүрістік терминалдық сызық. |
| `shortest_candidate_replay.tsv` | Сақталған candidate сызығына арналған replay кестесі. |
| `shortest_depth_proof.tsv` | Дәлел қабаттары бойынша сақталған breadth-search статистикасы. |

Бұл компонент дербес және `engine/` қалтасына тәуелді емес.

## Құрастыру

```bash
cd FINAL/shortest-game-generation
make
```

## Сақталған candidate-ті тексеру

```bash
./find_shortest_game --verify-only
```

Бұл сақталған 11 жартыжүрістік сызықты қайта ойнатады және оның терминалдық екенін тексереді. Ол `shortest_terminal_game.txt` және `shortest_candidate_replay.tsv` файлдарын қайта жазады.

## Толық іздеу мен дәлелді іске қосу

```bash
./find_shortest_game
```

Бұл үш нәрсе жасайды:

1. Конфигурацияланған тереңдік ішінде терминалдық сызық іздейді.
2. `11` жартыжүріске дейін терминалдық edge жоқ екенін дәлелдейді.
3. `shortest_terminal_game.txt`, `shortest_candidate_replay.tsv` және `shortest_depth_proof.tsv` файлдарын қайта жасайды.

Дәлел қадамы өте үлкен frontier-лерді материалдайды және көп уақыт пен жады алуы мүмкін.

## Сақталған ең қысқа сызық

`shortest_terminal_game.txt` мынаны қамтиды:

```text
1. 98 22
2. 87 12
3. 76 25
4. 65 13
5. 93 25
6. 54
```

Жүріс нотациясы - `selected_pit``landing_pit`, екеуі де бірден басталады. Мысалы, `98` ойыншы `9`-отауды таңдағанын және соңғы себілген құмалақ `8`-отауға түскенін білдіреді. Егер жүріс Тұздық жасаса, нотацияға `x` қосылады.

Соңғы жүріс - ойынның Ақ/P1 жасайтын 11-ші жартыжүрісі және ол Қазандарды `88-10` есебімен аяқтайды.

## Қосымша аргументтер

```bash
./find_shortest_game --verify-only
./find_shortest_game --no-proof
./find_shortest_game --max-depth 11 --beam 1000
```

`--verify-only` - ең жылдам қайта өндіру тексеруі. Әдепкі команда толық дәлелге бағытталған іске қосу болып табылады.
