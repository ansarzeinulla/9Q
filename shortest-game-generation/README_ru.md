# Генерация самой короткой партии

*Читать на других языках: [English](README.md) | [Қазақша](README_kk.md) | [Русский](README_ru.md) | [Кыргызча](README_ky.md)*

Эта папка содержит поиск самой короткой терминальной партии, использованный для исчерпывающего результата ранней игры в статье.

В статье сообщается, что до полухода `11` терминального состояния не существует, и приводится одна терминальная линия на полуходе `11` с итоговым счетом казанов `88-10` в пользу Белых/P1.

## Файлы

| Файл | Назначение |
| :--- | :--- |
| `find_shortest_game.cpp` | Автономный симулятор правил и поисковик самой короткой партии. |
| `Makefile` | Собирает `find_shortest_game`. |
| `shortest_terminal_game.txt` | Сохраненная 11-полуходовая терминальная линия. |
| `shortest_candidate_replay.tsv` | Таблица replay для сохраненной candidate-линии. |
| `shortest_depth_proof.tsv` | Сохраненная статистика breadth-search по слоям доказательства. |

Этот компонент автономен и не зависит от папки `engine/`.

## Сборка

```bash
cd FINAL/shortest-game-generation
make
```

## Проверка сохраненного candidate

```bash
./find_shortest_game --verify-only
```

Это переигрывает сохраненную 11-полуходовую линию и проверяет, что она терминальная. Команда перезаписывает `shortest_terminal_game.txt` и `shortest_candidate_replay.tsv`.

## Запуск полного поиска и доказательства

```bash
./find_shortest_game
```

Это выполняет три действия:

1. Ищет терминальную линию в пределах настроенной глубины.
2. Доказывает, что до полухода `11` терминального edge не существует.
3. Заново создает `shortest_terminal_game.txt`, `shortest_candidate_replay.tsv` и `shortest_depth_proof.tsv`.

Шаг доказательства материализует очень большие frontiers и может потребовать значительного времени и памяти.

## Сохраненная самая короткая линия

`shortest_terminal_game.txt` содержит:

```text
1. 98 22
2. 87 12
3. 76 25
4. 65 13
5. 93 25
6. 54
```

Нотация хода - `selected_pit``landing_pit`, обе позиции считаются с единицы. Например, `98` означает, что игрок выбрал лунку `9`, а последний посеянный кумалак приземлился в лунке `8`. Если ход создает Туздык, к нотации добавляется `x`.

Последний ход - 11-й полуход партии, сделанный Белыми/P1, и он завершает игру со счетом казанов `88-10`.

## Необязательные аргументы

```bash
./find_shortest_game --verify-only
./find_shortest_game --no-proof
./find_shortest_game --max-depth 11 --beam 1000
```

`--verify-only` - самая быстрая проверка воспроизводимости. Команда по умолчанию является полным запуском, ориентированным на доказательство.
