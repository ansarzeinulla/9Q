# Миллиард ойын генерациясы

*Басқа тілдерде оқыңыз: [English](README.md) | [Қазақша](README_kk.md) | [Русский](README_ru.md) | [Кыргызча](README_ky.md)*

Бұл қалта мақаладағы эмпирикалық ойын ағашын талдау үшін қолданылған кездейсоқ playout симуляторын қамтиды.

Мақалада мына нәтижелер берілген:

- `1,000,000,000` симуляцияланған кездейсоқ ойын
- `124,474,599,634` бақыланған тақта позициясы
- Осы позициялар бойынша `871,191,286,723` жинақталған заңды жүріс
- Кездейсоқ ойынның орташа ұзындығы шамамен `124.474` жартыжүріс
- Эмпирикалық орташа тармақталу коэффициенті шамамен `7.00`

Қоса берілген `billion_game_statistics.txt` - сақталған миллиард ойындық санағыш файлы.

## Файлдар

| Файл | Мақсаты |
| :--- | :--- |
| `generate_billion_games.cpp` | Random-vs-random симуляторы және статистика жинағышы. |
| `Makefile` | `generate_billion_games` бинарын құрастырады. |
| `billion_game_statistics.txt` | Мақаладағы іске қосудан алынған миллиард ойындық статистика. |
| `../engine/togyzkumalak_rules.*` | Симулятор қолданатын жергілікті ережелер тәуелділігі. |
| `../engine/position_hash.*` | Симулятор қолданатын жергілікті хэштелу тәуелділігі. |

## Құрастыру

```bash
cd FINAL/billion-game-generation
make
```

Makefile мыналарды компиляциялайды:

```text
generate_billion_games.cpp ../engine/togyzkumalak_rules.cpp ../engine/position_hash.cpp
```

## Шағын тест іске қосу

```bash
./generate_billion_games --num=1000 --seed=1 --threads=1 --fresh --stat=sample_billion_game_statistics.txt
```

## Симулятор режимдерінің бенчмаркі

```bash
./generate_billion_games --bench=100000 --seed=1 --threads=10
```

Қолжетімді режимдер:

| Режим | Мағынасы |
| :--- | :--- |
| `env` | Стандартты RNG бар бастапқы `ToguzEnv` жолы. |
| `env-fast-rng` | SplitMix RNG бар бастапқы `ToguzEnv` жолы. |
| `fast` | Ықшам бір ағынды симулятор. |
| `fast-prebuffer` | Алдын ала есептелген кездейсоқ мәндері бар ықшам симулятор. |
| `fast-parallel` | Worker ағындарына бөлінген ықшам симулятор. Бұл әдепкі режим. |

## Миллиард ойындық іске қосуды қайта өндіру

Қоса берілген `billion_game_statistics.txt` үстіне қосып жазбау үшін жаңа шығару файлын пайдаланыңыз:

```bash
./generate_billion_games --num=1000000000 --seed=709791810521833 --threads=10 --fresh --stat=billion_game_reproduction_statistics.txt
```

Маңызды: симулятор stats жолындағы бар санағыштарды жүктейді, жаңа іске қосуды қосады және файлды қайта жазады. Егер команданы қоса берілген `billion_game_statistics.txt` файлына қарсы іске қоссаңыз, миллиард ойындық санақтар бар миллиард ойындық санақтардың үстіне қосылады.

Бар шығару файлын елемей, нөлден бастау керек болса, `--fresh` қолданыңыз.

Іске қосу уақыты CPU ядроларының санына және компилятор оңтайландыруына қатты тәуелді. Толық миллиард ойындық іске қосу - ұзақ эксперимент; алдымен build дұрыстығын тексеру үшін шағын `--num` мәндерін қолданыңыз.

## Пайдалы опциялар

```bash
./generate_billion_games --num=1000000 --seed=12345
./generate_billion_games --num=1000000 --threads=10
./generate_billion_games --num=1000000 --max-steps=10000
./generate_billion_games --num=1000000 --fresh --stat=custom_billion_game_statistics.txt
./generate_billion_games --num=1000000 --mode=fast-parallel
```

## Шығару ескертпелері

- `billion_game_statistics.txt` ішіндегі санағыштар пайыз емес, raw counts.
- Файл адам оқи алатын қорытындыдан басталады, кейін скрипттер мен нақты тексерулер үшін raw `%key value` санағыштарын сақтайды.
- Ақ түс - `PLAYER_1`, бастапқы орнатылымдағы бірінші ойыншы.
- Жүріс индексі бар санағыштар ply/жартыжүрісті қолданады: `1` жүрісі - Ақтың бірінші жүрісі, `2` жүрісі - Қараның бірінші жүрісі және әрі қарай солай.
- `legalMoveAtPos` нөлден басталатын отау позицияларын `0..8` қолданады.
- `kumalakAtPos` `0..7` қолданады, себебі іске асырылған ереже бойынша тоғызыншы отауда Тұздық жасау заңды емес.
- `featureTrackedGames` - advanced feature санағыштарының бөлімі.
